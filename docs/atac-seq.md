# ATAC-seq: повторить фильм и собрать свой маршрут

Шаблон `atac-seq` содержит **46 эпизодов, 240,6 секунды**, русский и английский текст, повторы, паузу, перемотку и заметки с первоисточниками. Он воспроизводит проверенный путь: ДНК и гистоны → Tn5 → два события и библиотека → R1/R2 → координаты → количественные дорожки → происхождение длин фрагментов → распределения и интерпретация.

## Повторить одной командой

Из корня полной копии Visual Lesson Kit:

```sh
python3 create.py ../my-atac-film --template atac-seq \
  --title "ATAC-seq: от хроматина к карте доступности" \
  --lang ru --palette ocean
python3 ../my-atac-film/build/atac-film.py
```

Откройте `../my-atac-film/dist/lesson.html`. Для просмотра не нужны сервер, интернет или Node.js. Сборка требует Python 3.10+. Шрифты, исходные координаты, источники и лицензии включены. Английское начало: `--lang en`; фон/шрифт задаются через `--background white --font serif`. Сохранённые зрителем настройки могут переопределить начальное оформление.

`build/atac-film.py` последовательно воспроизводит координатные трассы из сохранённых mmCIF, гистоновые модели, RU/EN-тексты и автономный HTML. Скрипт работает из любой папки. Вариант с `--check` проверяет актуальность генерируемых данных и корректность входов сборки; как общий `bundle.py --check`, он не сравнивает уже записанный HTML. После изменений сначала выполните обычную сборку. Для побайтовой проверки библиотечного примера используйте `python3 tools/build-atac.py --check`.

## Собрать свой маршрут

Редактируйте `js/atac-config.js`. Пустой объект сохраняет весь фильм. `route` выбирает и упорядочивает готовые эпизоды; `overrides` меняет длительности и RU/EN-текст. Данные и ссылки на источники остаются у своих эпизодов.

```js
window.ATAC_FILM_CONFIG = {
  route: [
    'chromatin', 'nucleosome', 'nucleosome-real', 'histone-octamer',
    'wrapped-dna', 'linker', 'tn5', 'tn5-real', 'tn5-end-dna',
    'dock', 'stagger', 'tag-chemistry', 'two-events',
    'short-origin', 'nucleosomal-origin', 'contour-length', 'lengths'
  ],
  overrides: {
    'nucleosome-real': {motion: 4, hold: 5},
    lengths: {hold: 7, text: {
      ru: {
        title: 'Длины фрагментов связывают молекулу и измерение',
        caption: 'Вернёмся к учебной выборке из 150 фрагментов. Каждый вносит один вклад в свой интервал длины.'
      },
      en: {
        title: 'Fragment lengths connect molecules and measurements',
        caption: 'Return to the synthetic sample of 150 fragments. Each contributes once to its length bin.'
      }
    }}
  }
};
```

`motion` — секунды входящего движения, `hold` — секунды чтения после него. Первый эпизод показывается сразу; остальные движения должны быть конечными и положительными, паузы — конечными и неотрицательными. Объект внутри `route` также может задавать `{key, motion, hold, text}`. Поля текста: `title`, `caption`, `note`, `approach`, внутри `ru` и `en`. Этот фильм показывает основную подпись непрерывно; отдельный `approach` не заменяет её. Неизвестные и повторяющиеся ключи отклоняются.

Каждый эпизод хранит полное состояние. Соседние эпизоды исходного сценария сохраняют свои непрерывные приближения. При произвольной перестановке несовместимые виды сменяются через затухание и появление; скрытая геометрия пропущенного эпизода не появляется. Это не обещание непрерывного молекулярного перехода между любыми двумя состояниями. Согласуйте переходные фразы и проверьте новые переходы после монтажа.

В браузере `ATAC_FILM.catalog` содержит полный набор исходных состояний, `ATAC_FILM.cues` — выбранный маршрут, `ATAC_FILM.duration` — длительность. Не меняйте химические соединения или координаты через настройки времени: для другого источника нужно отдельно подготовить и проверить данные.

## Данные и границы применимости

Нуклеосома и Tn5 используют сохранённые экспериментальные структуры **1KX5** и **1MUH**. Общие и крупные планы сохраняют исходные точки, цвета, цепи и разрывы. Пунктир на некоторых гистоновых хвостах обозначает нулевую заполненность в депонированной модели. Камера меняет представление; фильм не вычисляет динамику молекулы.

В 1MUH нет геномной мишени или полных современных адаптеров. Размещение фермента около мишени, линкеры, схема переноса адаптера, чтение и распрямление фрагментов — объясняющие изображения. Переносимая цепь адаптера присоединяется своим 3′-концом к 5′-концу ДНК-мишени; Mg²⁺ назван кофактором без придуманной координационной геометрии.

Количественный пример синтетический: 150 исходных фрагментов, 12 известных PCR-копий, 300 концов; FRiP = 132/150 = 0,88 для заданных окон. Это не универсальный порог качества. Два примера происхождения короткой и длинной вставок не являются двумя записями этой выборки. Статистический peak caller и aligner не запускаются. Источники и воспроизведение входят в `assets/atac/SOURCES.md` и остальные руководства рядом с ним.

## Взять части в другой сценарий

[Компоненты ATAC](atac-components.md) описывают независимые акторы и их точные зависимости. Команда `--template atac-components` создаёт четыре обычные пошаговые сцены без часов полного фильма. Из них можно брать структурный вид, локатор, распрямление, чтение или гистограмму отдельно. В каждом новом проекте эти файлы доступны, но другие шаблоны не загружают их автоматически.

Сценарий на совершенно другую тему может использовать [CinemaTimeline](cinema-timeline.md), [ритм объяснения](cinematic-explanation.md), общий `F.driver` и ближние подписи `AtacCallouts`. Нуклеосомные и Tn5-акторы рассчитаны на включённые структуры; они не являются универсальным импортёром PDB. Для новых комплексов используйте [молекулярный конструктор](molecular-views.md).

## Проверить после изменений

```sh
python3 build/atac-film.py
python3 build/atac-film.py --check
node qa/atac/science.cjs
node qa/atac/remix.cjs
```

Научный аудит данных требует Node.js и Python 3 со стандартной библиотекой; браузер ему не нужен. Браузерные проверки требуют Playwright и установленного Chromium/Chrome; `NODE_PATH` может указывать на отдельную папку зависимостей. Выбор браузера — в `qa/trna/browser.cjs`.

Для полного исходного маршрута дополнительно запустите `visual.cjs`, `narrative.cjs`, `identity.cjs`, `tn5-identity.cjs`, `origin.cjs`, `local-story.cjs` и `text-paint.cjs` из `qa/atac/`. `visual.cjs` проверяет 503 кадра, включая восемь сочетаний языка/шрифта/фона; `contact.cjs` собирает листы для ручного просмотра. Полная инструкция и границы каждого теста — `qa/atac/README.md`. После перестановки эпизодов канонические проверки не заменяют проверку нового рассказа: `remix.cjs` проверяет активный маршрут и специальные случаи, затем автор просматривает свои пояснения и переходы.

Результаты переноса, хеши готовых примеров и точные границы выполненных проверок: [отчёт от 19 сентября 2026](atac-verification.md).
