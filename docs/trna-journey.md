# тРНК: повторить фильм и собрать свой вариант

Шаблон `trna-journey` воспроизводит непрерывный фильм **6:38, 39 опорных кадров**: последовательность → клеверный лист → L-форма → атомный стебель → D/T-контакты → Mg²⁺ и вода → объёмная атомная упаковка. Это одна дрожжевая тРНК(Phe), PDB **1EHZ**, с сохранёнными номерами и координатами. Русский и английский варианты, оформление, пауза и перемотка входят в шаблон.

## Повторить одной командой

Из корня полной копии Visual Lesson Kit:

```sh
python3 create.py ../my-trna-film --template trna-journey \
  --title "тРНК: от последовательности к атомам" \
  --lang ru --background black --palette ocean --font sans
python3 ../my-trna-film/build/bundle.py
```

Откройте `../my-trna-film/dist/lesson.html` и нажмите «Смотреть». Для английского начала замените `--lang ru` на `--lang en`. Нужны Python 3.10+ для сборки и современный браузер для просмотра; сервер и установка JavaScript-пакетов для просмотра не требуются. Шрифты, данные и лицензии включены. Файл работает без сети. Сохранённые настройки зрителя могут переопределить начальное оформление.

В созданном проекте редактируйте `js/trna-config.js`, затем снова запускайте `python3 build/bundle.py`. Можно открыть `index.html` во время работы. В библиотеке готовый пример находится в `examples/trna-journey.html`; воспроизводимая сборка — `python3 tools/build-trna-journey.py`, сравнение с новой сборкой — та же команда с `--check`.

## Собрать свой маршрут

Пустой `window.TRNA_FILM_CONFIG = {}` сохраняет весь фильм. `route` выбирает и упорядочивает готовые эпизоды. Строка использует исходный эпизод; объект дополнительно меняет длительность или текст. `overrides` применяет изменения по ключу, сохраняя весь маршрут, если `route` не указан.

Например, замените содержимое `js/trna-config.js` этим коротким обзором:

```js
window.TRNA_FILM_CONFIG = {
  route: [
    'sequence', 'cloverleaf', 'pairs', 'simplify',
    'cca', 'anticodon', 'spatial', 'rotation',
    'summary', 'volume', 'finale'
  ],
  overrides: {
    sequence: {hold: 10},
    spatial: {motion: 9, hold: 7},
    summary: {
      hold: 7,
      text: {
        ru: {
          title: 'Одна молекула — несколько представлений',
          caption: 'Буквы сохраняют порядок остатков, карта показывает пары, а пространственная модель — их взаимное положение.'
        },
        en: {
          title: 'One molecule, several representations',
          caption: 'Letters preserve residue order, the map shows pairs, and the spatial model shows their relative positions.'
        }
      }
    }
  }
};
```

Здесь CCA рассматривается перед антикодоном, а подробные атомные эпизоды пропущены. Каждый готовый эпизод содержит полное состояние, поэтому скрытые слои предыдущего эпизода не остаются после перестановки. Научную последовательность объяснения всё равно выбирает автор: от перестановки знакомые термины не становятся автоматически понятными. Переходные фразы тоже нужно согласовать с новым маршрутом.

`motion` — секунды входящего движения; `hold` — секунды неподвижного просмотра. Первый кадр не имеет входящего движения. Меняйте `title`, `caption`, `note` и `approach` через `text.ru` и `text.en`. Заголовок называет происходящее; нижняя подпись раскрывает его без повторения; `note` хранит подробности; `approach` — короткое введение на время движения. Если меняете текст, задавайте обе локали. Пауза должна быть конечной и неотрицательной; длительность каждого движения после первого кадра — конечной и строго положительной. Неизвестные и повторяющиеся ключи отклоняются.

Не редактируйте значения старых числовых строк в `js/trna-journey.js` ради времени: они идентифицируют исходные позы. Актуальное время рассчитывается из порядка, `motion` и `hold`. В браузере `TrnaJourney.cues` содержит собранный маршрут, а `TrnaJourney.duration` — его длительность.

| Часть | Ключи в исходном порядке |
|---|---|

| Пространственный обзор | `spatial`, `rotation`, `anticodon-close`, `anticodon-return`, `cca-close`, `arms` |

## Компоненты отдельно

Файлы входят во все новые проекты, но автоматически запускаются только в выбранном шаблоне. Для повторения визуального языка на другой теме начните с [временной шкалы](cinema-timeline.md) и [ритма объяснения](cinematic-explanation.md).

|---|---|

| `Cinema.mount` | Воспроизведение, точная пауза, перемотка и синхронизация оболочки. `js/trna-cinema.js`, `css/trna-cinema.css`, текущие `deck.js`, `player.js`, `film.js`. |
| `TrnaWorld.create(svg)` | 76 постоянных остатков, последовательность/клеверный лист/3D, общая камера и локатор. `trna-data.js`, `trna-atoms.js`, `trna-world.js` и общий SVG/Film/Layout runtime. Возвращает `paint(state)`, `dispose()` и узлы. |
| `TrnaAtoms.create(svg)` | 299 тяжёлых атомов стебля; `render(camera, options)` управляет выделением, раскрытием и контактами. `trna-atoms.js` содержит проверенный фрагмент. |
| `TrnaElbow.create(svg)` | Основания локтя и их контакты; `render(state, camera)`. Загрузите `trna-elbow-data.js`, затем `trna-elbow.js`. |
| `TrnaMagnesium.create(svg)` | Заряды, условная атмосфера, Mg560, вода и фосфаты; `render(state, camera)`, `dispose()`. Нужны `trna-magnesium-data.js`, проектор `TrnaAtoms` и рендер сфер. Отдельные метки — `trna-magnesium-labels.js`. |
| `TrnaSpacefill.create(svg)` | Все 1652 тяжёлых атома; `render(camera, amount)`, `dispose()`. Нужны `trna-spacefill-data.js`, проектор и рендер сфер. |

Для произвольных молекул используйте [конструктор молекулярных видов](molecular-views.md); готовая композиция тРНК привязана к 1EHZ, а не является универсальным импортёром любой РНК. При самостоятельной композиции создавайте акторы один раз и вызывайте `dispose()` через `ctx.onDispose`.

## Ритм и читаемость

Движение использует quintic smootherstep: нулевые скорость и ускорение на его концах. После движения идёт отдельная пауза: в полном варианте вступление — 8 секунд, насыщенные атомные кадры — 5–7 секунд. Подробная подпись проявляется после 95% **сглаженной интерполяции**, а не после 95% секунд перехода. До этого сложный переход сопровождает `approach`; в других эпизодах нижняя строка освобождает изображение. Это авторский порог, а не автоматическое доказательство видимости: после изменения камер и времён проверяйте промежуточные кадры.

У Mg-фрагментов C11/U12 разные метки; камера сохраняет три видимых водно-фосфатных пунктира. Атомные сферы используют общую глубину поверхности, поэтому пересекающиеся сферы не меняются местами целыми плоскими дисками. Изменение радиусов при раскрытии означает смену представления.

## Данные и границы выводов

Все координаты взяты из закреплённого 1EHZ mmCIF в `assets/rna-folding/`. Выборки, происхождение и литература находятся в `assets/trna/SOURCES.md`, `ELBOW-LITERATURE.md`, `MAGNESIUM-LITERATURE.md`. Генераторы в `build/trna-*.py` воспроизводят данные без сети. Сохранены 14 модификаций и оговорка о геометрии A31–Ψ39. В общем виде и финальной упаковке цвета обозначают участки цепи. В разборе нуклеотида они различают основание, сахар и фосфат; в Mg-эпизоде — ион, воду и фосфаты.

2D→3D сопоставляет изображения известной структуры; траектория сворачивания не рассчитывается. Показанный Mg — один конкретный гидратированный участок, а не универсальная схема действия магния. Пунктиры показывают контакты тяжёлых атомов; водороды и энергии связей не достраиваются. Финальная упаковка содержит тяжёлые атомы РНК без растворителя и ионов и не является поверхностью доступности растворителю.

## Проверить после изменений

Из созданного проекта:

```sh
python3 build/trna-data.py --check
python3 build/trna-elbow.py --check
python3 build/trna-spacefill.py --check
python3 build/trna-magnesium.py --check
python3 qa/trna/science.py
python3 qa/trna/magnesium-science.py
python3 build/bundle.py
python3 build/bundle.py --check
```

Для дополнительных проверок установите jsdom и Playwright в отдельное окружение QA и укажите `NODE_PATH` на его `node_modules` (или `JSDOM_MODULE` / `PLAYWRIGHT_MODULE` на соответствующий пакет). Проверки используют установленный Chromium Playwright; если его исполняемый файл отсутствует, пробуют установленный Chrome. `PLAYWRIGHT_CHANNEL` явно выбирает канал. Скрипты не скачивают браузер автоматически.

```sh
node --test qa/trna/atoms.cjs qa/trna/world.cjs qa/trna/elbow.cjs \
  qa/trna/spacefill.cjs qa/trna/sphere-depth.cjs qa/trna/magnesium.cjs \
  qa/trna/magnesium-story.cjs qa/trna/magnesium-projection.cjs \
  qa/trna/presentation-timing.cjs
node qa/trna/remix.cjs
node qa/trna/remix-locales.cjs
```

`remix.cjs` проверяет фактически выбранные эпизоды и обе локали. Для полного исходного фильма дополнительно используйте `qa/trna/film-playback.cjs`, `qa/trna/visual.cjs`, `qa/trna/magnesium-integration.cjs`, `qa/trna/spacefill-motion.cjs` и `qa/trna/spacefill-lifecycle.cjs`. Для попиксельной проверки `spacefill-motion.cjs` дополнительно нужен пакет `pngjs` (или `PNGJS_MODULE`). Некоторые из этих проверок намеренно требуют исходные эпизоды. Смотреть реальные промежуточные кадры нужно и после успешных тестов. Эмуляция браузера не заменяет проверку жестов на физическом телефоне.
