# Молекулярный конструктор: комплекс → крупный план

Этот шаблон повторяет два визуальных приёма урока о теломеразе: поворачиваемый белково-РНК-комплекс и увеличение его матрицы с постоянным локатором. Поставляются исходный PDB 7BG9, готовые данные и две редактируемые сцены на RU/EN. Рисунок собирается из координат; внешнего viewer, GPU и сети для просмотра не требуется.

## Быстрый старт

В корне библиотеки:

```sh
python3 create.py /absolute/new-lesson --template molecular-views --title "Теломераза: комплекс и матрица" --palette ocean
python3 /absolute/new-lesson/build/bundle.py
```

Откройте `/absolute/new-lesson/dist/lesson.html`. Для новой темы сначала выберите подходящую проверенную структуру и вопрос зрителя. Готовый сценарий находится в `js/recipes/molecular-views.js`: **два вызова**, `MolecularScenes.overview(...)` и `MolecularScenes.detail(...)`. Проекцию, анимационный цикл и ползунок переписывать не нужно.

## Что менять в рецепте

| Настройка | Что задаёт автор |
| --- | --- |
| `data` / `parts[].data` | Проверенный комплекс / атомные фрагменты одной исходной модели |
| `chains` | Цвет, ширину трассы и начальную прозрачность по author chain ID |
| `legend` / `parts[].label` | Названия и роли компонентов; структура не определяет их автоматически |
| `context` | Исходную цепь и выделенные остатки рядом с крупным планом |
| `states` | Ракурс, увеличение или прозрачность; полную реплику и заметку для каждого состояния |
| `qa`, `source`, `annotation` | Вопросы, первичный источник и пределы показанной модели |

Все поясняющие строки имеют форму `{ru: '…', en: '…'}`. Состояния задаются массивом: первый элемент — начальный вид, следующие — шаги. `camera` и `opacity` в следующих шагах дополняют предыдущие значения. У каждого состояния нужны `caption` и `note`. Пример состояния:

```js
{
  camera: {angle: 32, pitch: 24},
  opacity: {A: 0.18},
  caption: {ru: 'РНК видна внутри комплекса.', en: 'RNA is visible within the complex.'},
  note: {ru: 'Меняются камера и выделение; координаты сохранены.',
         en: 'Only camera and emphasis change; source coordinates are preserved.'}
}
```

`opacity` относится к chain ID в общем виде и к `parts[].id` в крупном плане. `angle` и `pitch` — градусы; `scale` — единицы сцены на Å. Для нового источника уберите примерный `camera`: пресет автоматически вместит ограничивающую сферу, безопасную при повороте. Для более тесного кадрирования задайте `camera: {origin, cx, cy, scale, angle, pitch}` и проверьте выбранный диапазон. `control: {label, min, max}` задаёт ручной поворот; `control: false` убирает его. Ручной ввод отменяет незавершённое движение. Длительность шага — `duration` в миллисекундах, по умолчанию 1900.

Пресеты оставляют свободные области для подписей: общий вид имеет до трёх пунктов легенды, крупный план — до двух атомных частей и один локатор. Для другой композиции используйте кирпичики ниже.

## Сборка из отдельных кирпичиков

- `MV.assembly` — трассы нескольких цепей, их выделение и общая сортировка глубины.
- `MV.detail` — атомные фрагменты RNA/DNA в одной камере, общая глубина и локатор.
- `MV.fit` — подгонка выбранных координат под рамку и ракурс.
- `MV.rig` — шаги, отменяемое движение, ручной ползунок и завершение при уходе со сцены.

Их можно комбинировать с собственными SVG-подписями и другими средствами kit. Точные сигнатуры, возвращаемые объекты и привязка подписи к атому — в [API кирпичиков](molecular-views-api.md). Низкоуровневые кольца, связи и координатный локатор — в [MC](molecular-coordinates.md).

При подключении к другому шаблону нужны `js/molecular-coordinates.js`, `js/molecular-views.js`, `js/molecular-scenes.js`, затем ваш реестр данных и рецепт. Загружайте их после обычных `dom`, `film`, `patterns` (создаёт K), `perspective`, `lesson`, `layout`, i18n и deck; сохраните ранний `appearance.js`. Готовый `molecular-views.html` содержит рабочий порядок. Добавлять сам HTML внутрь другой сцены не нужно.

## Как подготовить другой источник

Измените копию `assets/molecular-views/7BG9.config.json`, указав исходные цепи, модель, атомы трасс и RNA/DNA-остатки. Затем выполните переносимый импортёр:

```sh
python3 build/molecular-data.py \
  --source assets/molecular-views/7BG9.pdb \
  --config assets/molecular-views/7BG9.config.json \
  --json assets/molecular-views/7BG9.json \
  --js js/molecular-views-data.js --global MOLECULAR_VIEW_DATA
```

Замените пути для своего файла. `--check` проверяет совпадение производных данных без перезаписи. Конфигурация и ограничения описаны в [импортёре](molecular-data.md). Он поддерживает ограниченный набор PDB-представлений и канонические RNA/DNA-фрагменты, не выбирает биологическую сборку и не достраивает отсутствующие атомы. Для неподдерживаемых остатков или mmCIF подготовьте явно проверенные данные по контракту MV/MC. Сохраните исходник, URL, модель и хеш.

## Проверка результата

После правок соберите настоящий файл и проверьте его:

```sh
python3 build/bundle.py
python3 build/bundle.py --check
node qa/molecular-views/verify.cjs
```

Для браузерной проверки нужен Playwright в Node resolution path и Chrome (`VLK_BROWSER_CHANNEL`, по умолчанию `chrome`). В Codex сначала получите путь пакетов через `load_workspace_dependencies` и задайте `NODE_PATH` на возвращённую папку `node_modules`; не вшивайте путь текущей машины в проект. Результаты и screenshots записываются в `verification/molecular-views`. Можно передать проверяющему скрипту другой каталог проекта и вывода двумя позиционными аргументами.

Проверка проходит состояния RU/EN, два фона, два шрифта и три палитры, измеряет текст, записывает реальные промежуточные кадры и проверяет отмену движения ползунком. **Посмотрите изображения**: измерение рамки текста не проверяет все зазоры с молекулой. После смены исходника проверьте соответствие цепей, атомов, пропусков и связей оригиналу. Физические жесты телефона требуют отдельного испытания.

Трасса Cα/P не является молекулярной поверхностью. Кольца — условный способ показать выбранные атомы. Поворот камеры и ослабление цепи не вычисляют молекулярную динамику. Источник и ограничения готового примера: `assets/molecular-views/SOURCES.md`.
