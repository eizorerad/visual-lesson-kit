# Явные выборки с возвращением

`starter/js/resampling.js` добавляет `K.resampleMean`. Компонент показывает исходные записи, их копии в заранее заданных выборках и по одной точке арифметического среднего для каждой выборки. Он не генерирует случайные числа и не рассчитывает доверительные интервалы, p-value или число необходимых повторов. Уже существующий `N.bootstrapMeans` не дублируется.

## API

Загрузите компонент после `film.js`, `patterns.js` и общих `D`, `P`, `C`.

```js
const chart = K.resampleMean(parent, {
  population: [
    {id: 'D1', value: 2},
    {id: 'D2', value: 4},
    {id: 'D3', value: 8}
  ],
  samples: [
    {id: 'B1', sourceIds: ['D1', 'D1', 'D3']},
    {id: 'B2', sourceIds: ['D2', 'D3']}
  ],
  domain: [0, 10],
  x: 230, y: 242, width: 850,
  drawY: 363, meanY: 520,
  radius: 10, labelSize: 21
});

chart.setSample('B1', {draw: 1, collapse: 0}); // показать все три копии
chart.setSample('B1', {draw: 1, collapse: 1}); // среднее (2+2+8)/3 = 4
```

`population` и `samples` — непустые плотные массивы. У исходных наблюдений и выборок отдельные пространства уникальных непустых строковых ID. Каждая выборка содержит непустой плотный массив `sourceIds`. Повторение одного исходного ID внутри выборки допустимо и означает несколько копий той же записи. Повторять ID самой выборки нельзя. Неизвестные исходные ID, пустые списки, пропуски, `undefined` и неконечные значения вызывают исключение.

`domain` — явный возрастающий диапазон из двух конечных чисел с конечной длиной. Все исходные значения должны лежать внутри него. Числа за диапазоном не обрезаются. Указанные `x`, `y`, `width`, `drawY`, `meanY` обязательны и конечны; ширина положительна, правый край `x+width` конечен. `radius` и `labelSize` по умолчанию 10 и 21, оба положительны. Между исходной и выбранной строками требуется не меньше восьми радиусов; между выбранной строкой и областью средних — не меньше шести.

Все входные данные и вычисленная геометрия проверяются **до первой мутации DOM**. Данные копируются: исходные записи, диапазон, массив выборок, объекты выборок, списки `sourceIds`, чисел и копий заморожены. SVG-узлы остаются доступными для авторского оформления.

| Возвращаемое поле | Содержание |
| --- | --- |
| `g` | Общая SVG-группа. |
| `population`, `domain` | Замороженные снимки входных данных. |
| `originals` | `{g, dot, label, id, value}` для каждой исходной записи. |
| `samples` | `{id, sourceIds, values, mean, copies, meanPoint}` для каждой заданной выборки. |
| `samples[i].copies` | `{g, dot, label, sourceId, slot, value}`; копии одного источника имеют разные позиции `slot` и разные SVG-узлы. |
| `xScale(value)` | Одна числовая шкала `domain → [x,x+width]` для всех средних. |
| `setSample(id, {draw, collapse})` | Абсолютное состояние выбранной выборки. |

Оба progress-поля обязательны, конечны и ограничиваются диапазоном 0…1. `collapse > 0` допускается только после `draw = 1`. Невалидный вызов отклоняется до изменения узлов. Вызов не влияет на остальные выборки. Возврат к `{draw:0,collapse:0}` и повторное воспроизведение дают те же узлы и координаты. Анимацию времени задаёт внешний `F.step` / `F.tween` или driver; сам helper синхронный, не создаёт обработчиков и не требует очистки таймеров.

## Движение и смысл координат

Исходные наблюдения размещены равномерным списком в строке `y`; горизонтальный порядок там **не кодирует значение**. Каждая метка содержит ID и число. В строке `drawY` горизонтальное положение также означает номер позиции в выборке.

`draw` выпускает по одной копии: вниз от источника, через свободную горизонтальную полосу, затем вниз к своей позиции. Копия становится видимой после отделения от исходного кружка; подпись входит при прибытии. Белые исходники сохраняются. У копии есть `data-source-id`, `data-sample-id`, `data-copy-id` и неизменный `data-value`.

`collapse` сначала убирает подписи копий, затем сводит их в отдельной области над накопленными средними. Намеренное схождение означает вычисление, а не изменение исходных чисел. Сводный золотой кружок — новый объект с `data-resample-mean` и `data-value`; только он опускается на линию накопления. Он сразу имеет правильную числовую x-координату. Уже собранные средние не двигаются и не пересоздаются.

Средние, расположенные слишком близко по x, раскладываются по дополнительным вертикальным уровням. X всегда остаётся точным; вертикальный уровень служит только разделению точек. Если уровни не помещаются над `meanY`, компонент сообщает об ошибке. Он не рассчитывает общую компоновку текста: автор отвечает за достаточную ширину для числа исходников/копий, длину ID, размер шрифта и пути нескольких выборок. Одновременно анимировать несколько выборок в одной полосе не следует. Большой набор лучше показывать порциями. Безопасная область и отсутствие всех пересечений гарантируются тестами конкретного примера, а не произвольной длиной входных массивов.

## Парный bootstrap: рецепт автора

Для измерений «до» и «после» у одного донора сначала создайте одну запись различия на ID:

```js
const differences = pairedDonors.map(d => ({
  id: d.id,
  value: d.after - d.before
}));
```

До этой операции автор проверяет, что каждая пара относится к одному донору, обе величины конечны и имеют одинаковые единицы. Выборка с возвращением затем перечисляет **доноров целиком**. Один и тот же донор, выбранный дважды, даёт две копии его различия. Альтернативный внешний расчёт может переносить две исходные величины вместе по одному ID. Независимое пересэмплирование столбцов «до» и «после» разрушает парность.

Helper не определяет экспериментальную независимость. При связанных донорах, культурах, семьях или повторных измерениях нужна обоснованная схема пересэмплирования соответствующих единиц. Число копий не означает число новых независимых образцов. Небольшое количество специально выбранных демонстрационных списков не выдаётся за приближение доверительного интервала.

## Галерея и происхождение

Эпизод `10-resampling.js`, ID `resampling-means`, содержит три построения, четыре состояния заметок и два вопроса. В `POPULATION` явно заданы шесть синтетических изменений D1–D6: 2, 3, 4, 6, 7, 8. В `IDS` перечислены шесть выборок; их средние 25/6, 5, 6, 19/6, 20/3 и 11/3. Верхний список, выбранные копии и итоговые средние имеют разные объявленные роли. Ни одно число не является данными статьи.

Переход «наблюдения → выборка → одно среднее → несколько средних» адаптирован из локальных курсовых реализаций. Здесь списки выборок заданы явно, поэтому результат воспроизводим. Правило сохранения целого донора в парном примере — рецепт автора для обоснованной схемы зависимостей; оно не делает учебный набор реальным анализом. История кода и границы прав — в [provenance.md](provenance.md).

## Проверки

`node tests/resampling.cjs` использует `jsdom`, установленный в окружении. Проверяются допустимые повторы источника, точные средние, сохранение ID/DOM-узлов, детерминированное воспроизведение, неизменность снимков, отсутствие мутаций после ошибочных входов и переходов. Три построения проверяются в 121 моменте каждое: конечность SVG-атрибутов, границы видимых объектов и отсутствие пересечения движущихся копий с ранее накопленными средними. Это статическая проверка вычислений и геометрии; отображение шрифтов и управление уроком дополнительно проверяются в браузере.
