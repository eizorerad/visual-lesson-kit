# Целая SVG-область как кнопка

`T.svgButton` добавляет доступную область активации к авторскому рисунку. Подключите `js/interaction-regions.js` после `js/lesson.js` и `js/lib/i18n.js`, до модулей сцен. Модуль дополняет `T`; существующие компоненты и оболочка управления не меняются.

```js
const region = T.svgButton(svg, {
  id: 'source-a',
  box: { x: 100, y: 180, width: 270, height: 130 },
  label: 'Выбрать источник A', // каноническая строка, обычно RU
  onActivate: event => selectSource('a'),
  pressed: false,             // необязательно: boolean или null
  disabled: false,            // необязательно
  focusRing: true             // необязательно
});
ctx.onDispose(region.dispose);

const title = L.textBox(region.g, {
  id: 'source-a-title',
  x: 110, y: 200, width: 250, height: 70,
  text: 'Источник A', size: 25, padding: 8
});
ctx.onDispose(title.dispose);
```

Добавьте перевод полных строк в обычный языковой пакет. `label` задаёт доступное имя, а видимую подпись и рисунок создаёт автор. Используйте `L.textBox` и общую `L.watch(root, ctx)` сцены для измерения видимых подписей. Не вкладывайте другие кнопки, ссылки или поля ввода внутрь `region.g`.

Родитель — SVG-элемент, обычно `<svg>` или `<g>`; создание в ещё не подключённой к документу группе поддерживается. Координаты `box` относятся к локальной системе родителя. Все четыре значения должны быть конечными числами; ширина и высота — положительными. Проверяются также конечные правый и нижний края и геометрия рамки фокуса. Очень малая ширина при столь большой координате, что правый край округляется к левому, отвергается. Параметры копируются. Некорректные параметры конструктора не добавляют узлы; некорректное обновление оставляет предыдущее состояние целиком.

## API и состояние

Возвращается `{ g, hit, setBox, setPressed, setDisabled, setLabel, dispose }`.

| Элемент или метод | Поведение |
| --- | --- |
| `g` | Стабильная группа `role="button"`, `tabindex="0"`, `data-no-swipe`, доступное имя. Добавляйте сюда видимый мотив. |
| `hit` | Стабильный прозрачный `<rect>` с `pointer-events="all"` и `stroke="none"`. Вся площадь принимает указатель, включая пустые углы. |
| `setBox({x,y,width,height})` | Перемещает ту же область и рамку фокуса. Автор отдельно перемещает свои подписи и фигуры, либо трансформирует общую внешнюю группу. |
| `setPressed(boolean \| null)` | Устанавливает `aria-pressed`; `null` убирает атрибут. Не вызывает `onActivate`. |
| `setDisabled(boolean)` | Ставит `aria-disabled`, переключает `tabindex` между `-1` и `0`, отменяет начатое нажатие клавиши. Не вызывает callback. |
| `setLabel(sourceString)` | Принимает непустую каноническую строку, применяет текущий перевод. Смена языка сохраняет узлы и состояния. |
| `dispose()` | Удаляет группу, обработчики и языковую подписку. Повторный вызов безопасен. После удаления методы обновления бросают ошибку. |

Все методы обновления возвращают тот же объект API. `id` и `label` должны быть непустыми строками, `onActivate` — функцией. `pressed` по умолчанию отсутствует; `disabled` по умолчанию `false`, `focusRing` — `true`. Булевы параметры принимают именно boolean, без преобразования строк или чисел.

## Указатель, клавиатура и фокус

При стандартном SVG `pointer-events="visiblePainted"` прямоугольник с `fill="none"` принимает нажатие только на нарисованной части. Поэтому подпись может работать, а пустая часть плитки — нет. Здесь выделенный прозрачный прямоугольник имеет явный `pointer-events="all"`; обработчик находится на его группе. Нажатие на дочернюю подпись также активирует эту группу.

`onActivate(event)` вызывается один раз при клике, при первом `keydown` Enter или при `keyup` Space после соответствующего нажатия. Повтор клавиши, повторный `keydown` до отпускания, рекурсивная активация из callback и клики во время удержания клавиши не создают дополнительного вызова. Потеря фокуса и отключение кнопки отменяют незавершённое нажатие Space. Программное изменение состояния не активирует кнопку.

Оба события клавиш активации (`keydown` и `keyup`) вызывают `preventDefault()` и `stopPropagation()`, в том числе у отключённой кнопки. Клик тоже поглощается, чтобы область не запускала действие предка. Остальные клавиши проходят дальше. Отключённая область остаётся в геометрии указателя и поглощает активацию; она исключена из последовательного Tab-перехода, но допускает программный фокус. Для полного удаления области из сцены используйте `display:none` у её группы или внешнего контейнера: одна нулевая прозрачность не выключает SVG-нажатия.

Отдельный прямоугольник фокуса имеет `pointer-events="none"`, `fill="none"` и живой цвет `var(--color-focus)`. Он виден, пока сама группа в фокусе, включая фокус после клика; отключение скрывает рамку. Её линия шириной 2 единицы проходит на 2 единицы снаружи `box`. Оставляйте минимум 3 единицы до края обрезки или соседних подписей. Палитра меняет цвет без пересоздания узла.

**Выбор и фокус — разные состояния.** По умолчанию `pressed` меняет только ARIA: у выбранного элемента не возникает дополнительной рамки через числовые подписи или научные отметки. Автор показывает выбор своим мотивом — например, цветом фона или отдельным индикатором — из того же состояния, которое передаётся в `setPressed`. `focusRing:false` позволяет нарисовать собственный заметный фокус; в этом режиме помощник сохраняет стандартный браузерный outline как резерв. Не отключайте оба способа показа фокуса.

## Метаданные для проверки

Идентификатор — стабильная авторская строка; задавайте разные идентификаторы контролам одной сцены.

```html
<g data-vlk-button="source-a" role="button" data-no-swipe
   tabindex="0" aria-label="Выбрать источник A" aria-disabled="false">
  <rect data-vlk-hit="source-a" pointer-events="all" … />
  <rect data-vlk-focus="source-a" pointer-events="none" … />
  <!-- авторские фигуры и измеряемые подписи -->
</g>
```

Инспектор находит `[data-vlk-hit]`, затем ближайшего владельца `[data-vlk-button]`. Геометрия берётся из настоящего прямоугольника, а не из текста кнопки. Рамка `[data-vlk-focus]` не является областью активации. `aria-disabled="true"` явно обозначает отключённый контрол. Скрытые/неактивные области и пересечения соседних областей проверяются в контексте сцены; создание помощника само по себе не доказывает, что вышележащий элемент не перехватил указатель.

## Проверки

```sh
node --test tests/interaction-regions.cjs
```

Обычный запуск проверяет модель событий, атомарность обновлений, идентичность узлов, перевод, фокус и очистку. JSDOM не выполняет браузерное попадание указателя. Дополнительный тест запускается в настоящем Chromium, когда установлен Playwright:

```sh
VLK_NATIVE_BROWSER=1 node --test tests/interaction-regions.cjs
```

Можно указать `VLK_PLAYWRIGHT_MODULE` (путь к установленному модулю) и `VLK_BROWSER_EXECUTABLE` (путь к Chromium/Chrome). Этот тест физически нажимает пустую область старого `fill="none"` и воспроизводит пропуск, затем проверяет четыре внутренних угла и центр новой области, Enter/Space, отключение и цвет рамки после изменения палитры. Он не заменяет проверку расположения видимых подписей и соседних контролов в конкретной сцене на всех её языках и темах.
