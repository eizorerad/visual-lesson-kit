# Найти нужный приём

Начните с вопроса зрителя и выберите одну подходящую ветку. Открывайте подробности выбранной операции; к соседним веткам переходите, когда возникла конкретная зависимость. Обязательный краткий контракт — `AGENTS.md` проекта (`starter/AGENTS.md` в библиотеке).

```text
Научное объяснение
├─ Сценарий: вопрос → операция → вывод, повторяющаяся карта
├─ Движение: перемещение, преобразование, смена ракурса
├─ Компоновка: рамки текста, зазоры, крепление линий
├─ Статистика: разброс, перестановки, множественные проверки
│  └─ Распределения: квантили, повторные выборки, расстояния
├─ Биология: молекулярные акторы, CRISPR, хроматин, сплайсинг, клетки → доноры
├─ 3D: молекулярный комплекс → атомный план; клетка, бусина, капля, захват, три кода
├─ Химия: атомы и связи, реакции, энергия и скорость, pH, диффузия → биология
├─ Геометрия: окружность, проекции, линейное преобразование
├─ Данные: последовательности, матрицы, разбиения, рисунок статьи
├─ Взаимодействие: ползунки, вопросы, области нажатия
└─ Выпуск: оформление, языки, телефон, источники, проверка
```

Это дерево понятий, а не обязательный сценарий презентации. Точные идентификаторы и доступные операции выводит селектор:

```sh
# В корне библиотеки:
python3 docs/navigation/route.py --tree
python3 docs/navigation/route.py "перестановка меток"
python3 docs/navigation/route.py --show permutation
python3 docs/navigation/route.py --read permutation

# В созданном уроке замените docs/ на guide/:
python3 guide/navigation/route.py "подписи пересекают ось"
```

Поиск возвращает до трёх карточек: назначение, статус, нужные разделы руководств, пути к коду и необязательному примеру. `--show ID` показывает одну карточку; `--read ID --guide 2` открывает только второй указанный раздел. Большие выдержки делятся на части с явным `--offset`. Исполнение селектора читает метаданные, а не содержимое всех перечисленных файлов. Для этих команд не нужно сначала читать его Python-код или полный `catalog.json`.

Статусы: **ready** — готовый компонент; **compose** — сочетание общих инструментов и нового авторского рисунка; **external** — нужной вычислительной или графической возможности пока нет. Например, схема движения полимеразы относится к `molecular-animation`; расчёт фолдинга — к `molecular-simulation`. Список не заставляет подменять недостающую возможность посторонним готовым графиком.

Поиск использует небольшое двуязычное оглавление и ключевые слова. Если формулировка не нашлась, попробуйте синоним или дерево; нет необходимости читать всю библиотеку. API-контракта часто достаточно для использования компонента. Открывайте исходник, когда нужно адаптировать или исправить реализацию. Связанные карточки загружаются только по явному выбору.

Для нового эпизода карточка `scene` даёт минимальное подключение; `story` помогает выбрать ход объяснения. Для исправления существующего урока сразу выбирайте относящуюся к дефекту карточку. Перед выпуском используйте `export-qa` и проверки выбранных компонентов.

Карточка `molecular-check` ведёт к отдельному шаблону визуальной проверки семи новых молекулярных элементов, авторского движения и крупного плана. Он помогает повторять проверку и создавать собственный пример на тех же API; молекулярную физику не вычисляет.

Карточки `chemistry` и `physical-chemistry` разделяют схемы атомов, связей и реакций и численные модели с явными условиями применимости. Карточка `chemistry-bridge` ведёт к отдельному редактируемому уроку «Химия → биология», который связывает эти операции. Его рецепт, модули и руководства входят в каждый новый проект; шаблон запускается через `--template chemistry-bridge`.

Это управление чтением агента. Файлы остаются доступны, уже прочитанный текст автоматически не выгружается, а загрузка JavaScript в браузере регулируется отдельно. Индекс не обещает точную экономию токенов или безошибочный выбор.

For a connected RNA folding lesson, search `rna-folding` (also «укладка РНК», pairing/stacking, A-minor and hydrated magnesium). It provides a complete editable template, source coordinates and portable scientific/browser checks. For a reusable source-backed atomic fragment with a whole-molecule locator, select `molecular-coordinates`. These camera views do not compute folding trajectories; use `molecular-simulation` for that boundary.

Для готовой сборки пространственного белково-РНК-комплекса и атомного крупного плана выберите `molecular-views` («конструктор 3D», «теломераза») в ветке `three-dimensional`. Два пресета, независимые кирпичики камеры/трасс/локатора и переносимый импортёр PDB позволяют менять источник и сценарий без переписывания рисунка. Биологические запросы по-прежнему находят конструктор, а карточка `molecular-coordinates` в ветке биологии содержит ссылку на него.

В той же ветке `three-dimensional` находятся повторно используемые компоненты `V3`: объёмные антитела, поверхность клетки, твёрдая бусина с праймерами, водная капля и нити нуклеиновых кислот. Карточка `spatial-biology` ведёт к редактируемому шаблону из трёх полных сцен на RU/EN (24 состояния): мечение → отмывка → капля → лизис → совместный захват, затем клеточный штрихкод, признак и UMI, а затем две библиотеки RNA/ADT с общим клеточным кодом. Создать: `python3 create.py ../my-3d-lesson --template spatial-biology`. Исходники и руководство входят в каждый новый проект; сцены запускаются только при выборе этого шаблона. Это авторская объёмная схема; для атомных координат источника используйте `molecular-views` и `molecular-coordinates`. [Руководство 3D](three-dimensional.md) помогает выбрать представление. Имена шаблонов, API и пути JavaScript сохранены.

Для пути «энергия мотивов / колонки MSA → пары → 2D → пространственные ограничения» выберите `rna-prediction`. Карточка `rna-pair-molecule` даёт отдельный актор с сохранением индексов. Карточка `cinematic-explanation` объясняет стиль и временные кривые этой презентации для переноса на другие темы; нового глобального режима движения она не вводит.

Для непрерывного фильма «последовательность тРНК → клеверный лист → L-форма → атомы → контакты петель → Mg²⁺ → атомная упаковка» выберите `trna-journey`. Шаблон повторяет проверенный фильм и позволяет выбирать эпизоды, менять порядок, паузы и RU/EN-подписи в `js/trna-config.js`. Карточка `cinema-timeline` даёт отдельную временную шкалу для своей темы.

Для пути «ДНК и нуклеосома → Tn5 → парные прочтения → фрагменты и распределения» выберите `atac-seq`. Шаблон повторяет фильм 46 эпизодов / 240,6 с; `js/atac-config.js` позволяет выбирать порядок, длительность и RU/EN-текст. Карточка `atac-components` ведёт к четырём независимым сценам / 16 состояниям и API структурных видов, ближних подписей, распрямления вставок, чтения и гистограммы. Их можно использовать отдельно без полного фильма. Структуры 1KX5/1MUH отличаются от авторских схем и синтетических численных примеров; все источники и проверки доступны в создаваемом проекте.
