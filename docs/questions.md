# Вопросы к сцене и конспект урока

Проигрыватель поддерживает необязательное поле `qa` в каждой сцене. Q / Й открывает вопросы текущей сцены; G / П — поиск по вопросам всего урока в той же боковой панели. Отдельный HTML-конспект, сервер и сеть для поиска не нужны. Кнопка книги открывает единое пространство чтения; N / Т и вкладка «Пояснения» возвращают обычные заметки с выделением текущего шага.

## Содержание

```js
D.deck.register({
  id: 'mean-example',
  chapter: 'Среднее и разброс',
  title: 'Что скрывает среднее?',
  qa: [
    {
      q: 'Почему одинаковое среднее не означает одинаковые данные?',
      a: '<p>Среднее описывает центр. Отдельные значения могут иметь разный разброс.</p>',
      source: 'Учебное объяснение автора'
    }
  ],
  notes: [F.note('Начальное состояние')],
  build(ctx) {
    return F.stage(ctx, 'Что скрывает среднее?').root;
  }
});
```

- `q` — вопрос, обычный текст.
- `a` — ответ, авторский HTML: абзацы, выделение, списки и формулы в тексте. Как и заметки сцены, это доверенный материал автора: не вставляйте непроверенный HTML статьи или страницы напрямую. Внешнюю ссылку на источник задавайте отдельным `url`.
- `source` — необязательная подпись источника обычным текстом. Без `url` остаётся текстом; HTML-разметка здесь не выполняется.
- `url` — необязательный **полный** адрес `https://…` или `http://…`. Относительные адреса, `//…`, `javascript:…`, `data:…` и некорректные URL не создают ссылку. Подпись сохраняется текстом. При допустимом URL без подписи используется «Источник»; ссылка открывается с `noopener noreferrer`.

Для статьи автор добавляет проверенный URL именно к соответствующему ответу. Проигрыватель не подставляет глобальную статью, путь к другой презентации или вымышленную ссылку. Для учебного примера можно опустить оба поля. `qa` можно полностью опустить; панель сообщит, что вопросов к этой сцене пока нет. Элементы без строковых `q` и `a` не показываются.

## Подключение

Функциональность входит в `js/deck.js`; дополнительный JavaScript-файл не нужен. Используйте актуальную разметку из `starter/index.html`: режимы `notes`, `questions`, `guide` находятся во вкладках внутри `#notes`, а в нижнем `#chrome` остаётся одна кнопка `data-action="reading"`. Подключите `css/questions.css`, затем последним `css/shell.css`. Сохраняются `#notes`, `#notesHead`, `#notesBody`; поисковое поле и результаты создаются автоматически.

Кнопка «Все вопросы урока · поиск» внутри текущих вопросов также открывает конспект. Полный контракт клавиатуры и разметки — [shell.md](shell.md). Для переноса версии в существующий урок следуйте [upgrading.md](upgrading.md), сохраняя эпизоды и оба авторских языковых пакета. Сборщик встроит стили и код обычным способом.

## Поведение

Повторное нажатие горячей клавиши активного режима или кнопки книги закрывает панель; нажатие уже выбранной вкладки оставляет её открытой. Escape закрывает её; если открыты справка или оглавление, Escape сначала закрывает верхний интерфейс. Вкладки показывают выбранный режим через `aria-selected`, имеют `role="tab"` и связаны с `#notesBody`; для совместимости сохранены `aria-pressed` и класс `is-on`. Кнопка книги сообщает `aria-expanded`.

Текущие вопросы следуют за сменой сцены; заметки продолжают следовать за шагами. На одном шаге Q&A не перестраивается при обновлении проигрывателя: раскрытие ответов и положение чтения сохраняются. Вопросы текущей сцены раскрыты сразу; общий конспект использует сворачиваемые ответы. Поиск без учёта регистра проверяет вопрос, текст ответа, подпись источника и название сцены. Непустой запрос раскрывает найденные ответы. Нажатие названия сцены переходит к её начальному состоянию и текущим вопросам. Запрос сохраняется при возвращении в конспект.

Когда фокус внутри панели, стрелки, пробел, Page Up/Down, Home/End и повторяемые клавиши остаются доступны для нативного чтения, прокрутки и раскрытия ответов. Они не перелистывают сцену. В поисковой строке буквы горячих клавиш вводятся как текст; Escape по-прежнему закрывает панель. Для управления шагом используйте кнопки проигрывателя или верните фокус на холст.

## Происхождение и проверка

Механизм `scene.qa` адаптирован из локальных курсовых реализаций: вопросы отделены от пошаговых заметок, у ответа может быть собственный источник, а клавиши чтения не перелистывают сцену. Поиск и переход к сцене реализованы внутри переносимого урока. Общая история кода и границы прав — в [provenance.md](provenance.md).

`node --test tests/questions.cjs` проверяет текущие вопросы, пустую сцену, заметки и возврат по шагам, поиск и переход, сохранение поля поиска, клавиатуру, источники и отсутствие придуманных ссылок. Нужен установленный jsdom; допускается `NODE_PATH`. Эти проверки не заменяют просмотр широкой и узкой раскладки в живом браузере.
