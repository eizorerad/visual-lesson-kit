# Зазоры между подписями и геометрией

Подпись должна оставаться читаемой при изменении параметра, языка и шрифта. Сначала выделите ей реальную область, затем разместите вокруг неё вспомогательные линии. Эти приёмы используют существующие API; автоматического решателя размещения здесь нет. Контракты текста описаны в [layout.md](layout.md), точки крепления — в [explanation-geometry.md](explanation-geometry.md).

## Резервируйте всю формулу

Область формулы включает её полную ширину и высоту: степени, индексы, скобки, дробь и внутренние отступы. Одна базовая линия или центр строки не описывает эту область. Если есть видимая рамка, используйте её действительные размеры. Если формула собрана из нескольких узлов, предусмотрите общий внешний прямоугольник для всей конструкции.

Вокруг этой области оставьте зазор до **внешнего края штриха**, а не только до его осевой линии. Для обычного центрированного штриха ширины `w` к зазору добавляется `w / 2`. Проверяйте максимальную ширину анимированного потока; наконечники, выступающие соединения и концы линий требуют учёта собственной формы. Масштабированный SVG и `vector-effect="non-scaling-stroke"` нельзя сравнивать, смешивая локальные единицы и пиксели экрана.

Пример отводит вспомогательную горизонтальную линию выше всей формулы. Числа здесь — только размеры композиции. Оба примера — независимые фрагменты `build(ctx)`: `svg` взят из `F.stage`, который подключает `L.watch` и очистку сцены. Для собственного SVG подключите `L.watch(root, ctx)` один раз, чтобы смена шрифта и языка обновляла размещение. Загружены `F`, `L`, `K` и семантические цвета `C`.

```js
const formulaBox = {x: 480, y: 270, width: 160, height: 90};
const formula = L.textBox(svg, {
  ...formulaBox, id: 'formula', text: '2ˣ',
  size: 30, padding: 14, color: C.white
});
const gap = 18, maxStroke = 10;
const [centerX, topY] = K.boxAnchor(formulaBox, 'top');
const guideY = topY - gap - maxStroke / 2;
const guide = F.line(svg, centerX - 180, guideY,
  centerX + 180, guideY, C.grey, maxStroke);
console.assert(guideY + maxStroke / 2 === formulaBox.y - gap);
```

`K.boxAnchor` возвращает геометрическую границу без поправки на толщину. `L.textBox` измеряет текст, но не отодвигает соседние линии. В примере нижний край штриха находится на 18 единиц выше выделенной области. Для изменяющейся формулы обновляйте общий frame и `formula.setBox(frame)` вместе с направляющей.

Не добавляйте декоративные вертикальные черты рядом с `2ˣ`: пара таких черт читается как `|2ˣ|`, то есть математический модуль. Штрихи границы интервала допустимы, когда они действительно обозначают его концы и этот смысл объяснён. Для выделения формулы достаточно свободного места, подписи операции или смыслового цвета.

## Ось, легенда и движущийся вектор

При конфликте с научной осью переносите подпись, числовой readout или блок легенды. Например, отведите две области легенды по разные стороны вертикальной оси вместо одной строки, пересекающей её. Вспомогательную связь можно провести в обход текстового блока; количественную ось не изгибайте ради текста. Координаты наблюдений, длины векторов, масштаб и основные контуры сохраняются.

Для вращающегося вектора выбирайте сторону подписи по полуплоскости его **текущей проекции**: справа от вертикальной оси — справа от конца вектора, слева — слева. Постоянный подъём подписи, удачный для одного угла, не решает пересечение при другом угле. Следующий пример меняет только область текста; точка и стрелка получают исходные координаты.

```js
const origin = {x: 620, y: 380}, axisX = origin.x;
F.line(svg, axisX, 170, axisX, 560, C.grey, 2);
const vector = F.arrow(svg, C.blue, 4);
const tip = F.dot(svg, origin.x, origin.y, 6, C.blue);
const labelWidth = 96, labelHeight = 56, offset = 18;
const tag = L.textBox(svg, {
  id: 'vector.label', x: 638, y: 352,
  width: labelWidth, height: labelHeight,
  text: 'v', size: 26, padding: 8, color: C.blue
});
function paint(point) {
  vector.set(origin.x, origin.y, point.x, point.y);
  F.pos(tip, point.x, point.y);
  tag.setBox({
    x: point.x >= axisX ? point.x + offset
      : point.x - offset - labelWidth,
    y: point.y - labelHeight / 2,
    width: labelWidth, height: labelHeight
  });
}
paint({x: 720, y: 290}); // also try x = 520 and x = axisX
```

Здесь `point.x` и `axisX` уже выражены в одной системе координат рисунка после проекции; это не сравнение мировой координаты с браузерным `getBoundingClientRect()`. Предполагаются вертикальная ось и свободное место с обеих сторон. На самой оси пример выбирает правую сторону. Это локальное правило, а не гарантия отсутствия всех пересечений: проверьте соседние объекты, края холста и момент смены стороны. `setBox` — метод объекта, возвращённого `L.textBox`; отдельной функции `L.setBox` нет.

Можно сократить протяжённость или густоту **второстепенной** сетки, ослабить её штрих, если деления остаются понятны. Сохраняйте основную геометрию и необходимые шкалы. Постоянная безопасная полоса для подписей полезна только при ясной связи «подпись → точка»: её могут сохранять ID, смысловой цвет и близость; при необходимости добавьте короткую однозначную выноску из текущей точки. Далёкая полоса с пересекающимися выносками может сделать рисунок менее понятным.

## Проверяйте контакт, а не только прямоугольники

Пересечение измеренного font bounding box с линией — кандидат на визуальную проверку, а не доказательство пересечения штриха с видимыми глифами: прямоугольник содержит пустоты. Но касание реального штриха букв или степени тоже требует исправления, даже если подпись формально помещается в выделенный блок. Осмотрите шрифт после загрузки, без маскировки проблемы непрозрачной плашкой поверх важных данных.

- Проверьте RU/EN в Source Sans 3 и Source Serif 4, на чёрном и белом фоне. Не уменьшайте шрифт и не обрезайте текст для получения чистого отчёта.
- Для каждого ползунка проверьте оба края, внутренние значения и места смены стороны или длины подписи. Для вращения включите положения около осей и обе полуплоскости.
- Осмотрите **полный замкнутый контур** окружности или эллипса: проверка ближайшей вершины, конца линии либо одного участка дуги пропустит пересечение с другой стороны подписи.
- Проверьте начальные, промежуточные и конечные кадры, появление соседних слоёв и фазу самого толстого потока. Безопасные конечные положения не гарантируют безопасный путь.

После загрузки шрифтов используйте `await L.ready(root)` и `L.audit(root)` для контрактов текста. Эти проверки подтверждают размещение внутри предназначенных областей; **`L.audit` не проверяет пересечения со штрихами, окружностями, стрелками или потоками**. Дополняйте отчёт с числом проверенных и неизмеренных областей просмотром реальных кадров; не называйте проверку нескольких состояний доказательством для всего непрерывного движения.
