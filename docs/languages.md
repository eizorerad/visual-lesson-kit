# Язык сцены, пояснений и управления

Текущая галерея содержит русский и английский: 13 сцен, 52 полных пояснения и 26 вопросов с ответами. Пункт **Язык · RU / EN** в меню «Ещё» показывает текущий язык; нажатие переключает его. В шапке чтения есть такая же кнопка RU/EN рядом с крестиком: она позволяет сменить язык, сохраняя открытый текст. Работает также `L` / `Д`. Пока фокус находится в поле поиска или другом вводе, буквы остаются вводом текста.

Начальный язык выбирается в порядке: `?lang=en` в адресе → сохранённый выбор для этого урока → `LESSON.lang` → русский. При переключении обновляются адрес (остальные параметры и `#сцена.шаг` сохраняются), локальное предпочтение и `html.lang`. Ошибка доступа к localStorage не мешает переключению.

```sh
python3 /path/to/visual-lesson-kit/create.py /absolute/path/new-lesson --lang en --title "My lesson"
```

В обоих случаях копируются оба языка. `--lang` задаёт начальный язык, не удаляет второй. Готовый автономный HTML также содержит оба пакета; для смены языка сеть не нужна.

## Что сохраняется при переключении

Сцена не строится заново. Остаются текущий шаг, существующие SVG-объекты, выбранные пары, численные значения, ползунки и текущая анимация. Переводятся существующие текстовые узлы и `title`, `aria-label`, `placeholder`, `alt`; новые строки очередного `paint()` обрабатываются до следующей браузерной отрисовки через MutationObserver.

Заметки и QA выбираются из авторского пакета по `scene.id`. Поиск работает по вопросам, ответам, источникам и названиям в выбранном языке. Введённый запрос не переводится автоматически. При смене языка сохраняются открытые ответы, логический фокус вопроса и позиция прокрутки панели. Уже открытые пояснения и диалоги источников тоже получают выбранный язык.

Серые служебные надписи над заголовком и внизу холста скрыты. Сведения об источнике находятся в раскрываемом разделе в конце вкладки «Пояснения» / Notes. Основная объясняющая реплика внизу сцены остаётся частью содержания.

## Авторские пакеты

Исходные русские тексты остаются в эпизодах. `js/i18n/en.js` содержит подписи и интерфейс; `js/i18n/en-notes.js` — полные заметки и QA первых одиннадцати сцен; `js/i18n/en-perspective.js` — все переводы двух пространственных примеров. Файлы подключаются после `js/lib/i18n.js`, перед сценами. Повторный `pack` дополняет тот же язык, поэтому длинные материалы можно разделить по файлам.

```js
D.i18n.pack('en', {
  label: 'EN',
  strings: {
    'Одна выборка': 'One sample',
    'Выбранные записи': 'Selected records'
  },
  patterns: [
    {match: /^Выбрано (\d+) записей$/, replace: 'Selected $1 records'}
  ],
  notes: {'my-scene': ['<p>Initial explanation.</p>', '<p>After the step.</p>']},
  qa: {'my-scene': [{q:'What is one point?', a:'One observation.', source:'Teaching example'}]},
  ui: {notesHead:'Notes · current step highlighted', notesEmpty:'No notes for this scene.'}
});
```

`strings` — полные исходные строки без краевых пробелов. При переводе краевые пробелы сохраняются. `patterns` — регулярные выражения, обязательно ограниченные `^` и `$`, для полного динамического текста. Они не должны подменять отдельные слова в произвольных научных фразах. Сначала ищется точное совпадение, затем первый подходящий шаблон. Это авторские словари, а не автоматический переводчик: неизвестная строка остаётся исходной.

В эпизоде продолжайте записывать исходные строки (`label.textContent = 'Выбрано ' + count + ' записей'`). Наблюдатель знает исходный текст каждого узла и восстанавливает его при возврате к RU. Не записывайте заранее переведённую строку поверх этого узла: без исходного ключа нельзя надёжно восстановить её русский вариант. `D.i18n.text(source)` полезен для поиска и других вычислений над локализованными строками вне таких постоянных узлов.

- `D.i18n.apply(root)` синхронно переводит текстовое поддерево, не меняя его структуры.
- `D.i18n.observe(root)` применяет перевод и наблюдает за последующими изменениями; возвращает функцию отключения. Проигрыватель уже наблюдает за `document.body`.
- `D.i18n.onChange(fn)` возвращает отписку. Для дополнительных подписок сцены регистрируйте её через `ctx.onDispose`.
- `D.i18n.notes(scene)` / `qa(scene)` возвращают выбранный вариант либо исходный текст.
- `D.i18n.untranslated(scenes)` отмечает отсутствующие заметки/QA и несовпадающее число элементов. Эта проверка не оценивает качество перевода и не доказывает покрытие всех динамических строк.

`script`, `style`, `code`, `pre`, `textarea`, редактируемые области и элементы с `data-i18n-ignore` исключены. Числовые SVG-атрибуты, значения input, URL и `data-*` не переводятся. Формулы, единицы и имена объектов необходимо проверить при подготовке словаря.

Оригинальные изображения статьи сохраняют язык оригинала; переводятся их окружающие подписи и пояснения. Для собственных иллюстраций, которым нужен другой язык внутри изображения, автор может явно подготовить отдельные assets. Библиотека не перерисовывает научный источник автоматически.

## Следующий урок и проверка

При изменении содержания обновите оба пакета: старые учебные переводы не являются переводом новой статьи. Сопоставьте все ID, состояния, числа и источники. `tools/extract-translations.cjs` в самой библиотеке собирает подписи исходной галереи для аудита; это вспомогательный Node/jsdom-инструмент, не зависимость урока.

Проверьте оба языка на каждом состоянии, затем ползунки, выбор объектов, раскрытие подсказки и диалог источника. Особенно важны промежуточные динамические строки, которые отсутствуют в начальном/конечном кадре. Проверьте длину английских подписей в браузере: наличие перевода не гарантирует подходящую вёрстку.

Механизм пакетов и заметок по ID сцены адаптирован из локальных курсовых реализаций. Библиотека дополняет его переводом динамических подписей и QA, полной оболочкой и переключением без сброса состояния. История кода и границы прав — в [provenance.md](provenance.md).

Оболочка использует постоянные размеры контролов и пространства под ними: длина перевода и число шагов не меняют геометрию сцены. Все три режима чтения находятся во вкладках, язык и скорость — в меню «Ещё». Точки подключения и перенос — [shell.md](shell.md), [upgrading.md](upgrading.md).
