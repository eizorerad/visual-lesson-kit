# Вопросы и последовательности

Эти компоненты добавлены к `F`, `T`, `K` как переносимые компоненты с явно заданными учебными данными. Подключите `js/inquiry.js` после `lesson.js`, `film.js`, `patterns.js`, а `css/inquiry.css` — после основных стилей. Эпизоды `05-ponder.js` и `06-sequence.js` показывают использование. Все их значения и отношения учебные.

## Вопрос до ответа: `T.ponder`

```js
const question = T.ponder(v.root, {
  question: 'Одинаковое среднее означает одинаковый разброс?',
  hint: 'Сравните крайние значения.',
  answer: 'Нет: два списка могут иметь одно среднее и разные диапазоны.',
  x: 660, y: 216, width: 530, height: 330,
  onChange(next) {
    // Вызывается только при ручном нажатии кнопки, не из setState().
    state.hint = Number(next.hint);
    state.answer = Number(next.answer);
  }
});
question.setState({hint: false, answer: true});
```

`question` и `answer` — непустые текстовые строки; `hint` — необязательная строка. Компонент выводит текст, не интерпретирует HTML. Координаты конечные, размеры положительные. Значения по умолчанию: x=665, y=205, width=500, height=340. Компонент размещается в HTML-сцене и не создаёт перекрывающую весь холст подложку.

Возвращаемый объект:

- `el`, `question`, `hint`, `answer` — постоянные DOM-узлы.
- `hintButton`, `answerButton` — обычные кнопки с `aria-controls` и `aria-expanded`.
- `setState({hint,answer})` принимает логические состояния и возвращает API. Отсутствующее поле сохраняет своё значение.
- `showHint()` / `hideHint()` и `reveal()` / `hide()` изменяют соответствующий раздел; `hide()` скрывает только ответ.
- `state()` возвращает копию двух логических состояний.

Оба раздела первоначально скрыты. Подсказка и ответ раскрываются независимо. При пустой подсказке её кнопка отсутствует в интерфейсе. Методы меняют состояние синхронно: автор связывает их с `F.step`/`paint` и собственной анимацией рисунка. `onChange` нужен, чтобы ручной выбор обновлял и состояние эпизода; программная перерисовка не вызывает этот callback рекурсивно.

Кнопки работают с клавиатуры. Helper не устанавливает глобальные обработчики клавиш и не перехватывает стрелки. Enter и пробел активируют обычную кнопку; стрелки остаются проигрывателю. Подсказка и ответ имеют зарезервированные области, поэтому появление текста не сдвигает вопрос и кнопки. Длинный авторский текст может потребовать увеличения области или сокращения; нельзя считать произвольную строку автоматически проверенной по размерам.

В примере сначала показаны только одинаковые средние. Затем появляются наблюдения A=[4,5,6], B=[1,5,9], их диапазоны и ответ. Это контрпример равенству распределений при равных средних, а не статистический тест и не оценка неопределённости среднего.

Ручное раскрытие должно также обновлять рисунок и текущую реплику. В эпизоде 5 подсказка сразу показывает значения и диапазоны, на которые она ссылается; подпись после раскрытия больше не утверждает, что видны только средние. Регрессия проверяется в `tests/ponder-caption.cjs`.

## Постоянные символы: `K.sequenceTrack`

```js
const sequence = K.sequenceTrack(stage, {
  tokens: [
    {id:'left', label:'A', color:C.white},
    {id:'middle', label:'B', color:C.white},
    {id:'right', label:'C', color:C.white}
  ],
  positions: [{x:300,y:300}, {x:500,y:300}, {x:700,y:300}],
  pairs: [[0,2]],
  radius: 23,
  onSelect(index) { /* индекс выбран пользователем */ }
});
sequence.setPositions([{x:300,y:250}, {x:500,y:400}, {x:700,y:250}]);
sequence.setPairsVisible(1);
sequence.select(0);
```

`tokens` — непустой массив строк либо объектов `{id?,label,color?}`. Строка обозначает один символ/токен; для короткой строки последовательности автор может явно передать `Array.from(text)`. У каждого объекта сохраняются ID и текст. Если ID отсутствует, используется `token-0`, `token-1` и т. д. Пустые метки и повторяющиеся ID отклоняются. Входные объекты копируются и не изменяются.

`positions` содержит ровно одну точку `{x,y}` с конечными координатами на токен. Без него используется строка с параметрами x=200, y=320, gap=80. `gap` и `radius` должны быть положительными. По умолчанию radius=22; `showIndices:false` скрывает подписи индексов. `color`, `pairColor`, `indexColor` и `label` позволяют задать оформление и доступное название группы.

`pairs` — массив пар **нулевых индексов**, например `[0,7]`. Индексы должны существовать и различаться; повтор одной неориентированной пары, в том числе `[7,0]` после `[0,7]`, отклоняется. Один токен может иметь несколько явно заданных соседей: helper не накладывает правила биологического спаривания. Пары не вычисляются из букв или геометрии.

API возвращает:

- `g` — группу, `nodes` — постоянные группы символов, `edges` — постоянные отрезки пар, `backbone` — линию последовательности.
- `tokens`, `pairs`, `positions` — защищённые копии данных; `.positions` обновляется после `setPositions`.
- `setPositions(array)` меняет координаты тех же узлов, концов связей и пути, сохраняя текст и ID. Неверный набор отклоняется целиком до изменения рисунка.
- `setPairsVisible(t)` ограничивает конечное число t диапазоном 0…1 и изменяет видимость связей.
- `select(index|null)` выделяет выбранный узел, всех его явно заданных соседей и связанные рёбра. `selection()` возвращает выбранный индекс или null.

Программный `select` не вызывает `onSelect`; ручной щелчок, Enter или пробел вызывают. Каждый символ доступен с клавиатуры, `aria-pressed` отражает выбор. Стрелки не перехватываются. Выбранный контур и связь используют роль focus (`C.gold`), связанный контур — primary (`C.blue`); фактические оттенки зависят от палитры. Текст символа сохраняет свой исходный цвет.

Для анимации автор вычисляет массив положений из своего состояния и передаёт его в `setPositions()` на каждом кадре. Компонент не симулирует физику и не гарантирует отсутствие пересечений для произвольной траектории. В `06-sequence.js` A–H изгибаются по дуге; порядок вдоль цепи сохраняется, соседние символы не меняются местами. Явные пары 1↔8, 2↔7, 3↔6 служат только демонстрацией отношений. Это не предсказанная структура РНК.

## Происхождение и границы

Приёмы вопроса перед ответом и сохранения символов при смене расположения адаптированы из локальных курсовых реализаций. Здесь `T.ponder` задаёт отдельные состояния вопроса, подсказки и ответа, а `K.sequenceTrack` разделяет координаты, индексы и явно заданные отношения. Компонент не содержит биологического правила спаривания, предсказателя структуры или универсального linked brushing. Сведения об истории кода и правах — в [provenance.md](provenance.md).

## Проверка

```sh
node --test tests/inquiry.cjs
```

Нужен dev-пакет jsdom из `package.json`; браузерный runtime не получает новых внешних зависимостей. Тесты написаны до helper, первоначально упали из-за отсутствующих API, затем проверили отдельные состояния вопроса, клавиатурное поведение, 41 промежуточное положение последовательности, ID, концы связей и атомарный отказ на неправильных данных. Проверка двух примеров дополнительно прошла 709 промежуточных кадров и ручных положений ползунка; минимальное расстояние между центрами символов было 99,16 при диаметре 46. Это расчётная проверка, а не утверждение о живом просмотре в браузере.
