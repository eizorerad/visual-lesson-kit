# Visual Lesson Kit

[English](README.md) · [Подключение к Codex](docs/codex-setup.md)

**Начало для агента:** [дерево понятий](docs/START.md) → нужная карточка → конкретный раздел. Поиск: `python3 docs/navigation/route.py "ваша задача"`. Он читает метаданные и возвращает выбранные ссылки; полный код библиотеки загружать не требуется.

Версия **0.19.0**. Переносимая библиотека интерактивных HTML-уроков с самостоятельной визуальной системой: чёрный или белый холст, переключаемые палитры и шрифты, постоянные смысловые роли цветов и последовательное преобразование объектов. Правила оформления и палитра описаны в [theme.md](docs/theme.md).

**Отдельный раздел 3D:** [пространственная биология](docs/three-dimensional.md) — повторно используемые компоненты `V3` для объёмных антител, поверхности клетки, твёрдой бусины с праймерами, водной капли и молекулярных нитей. Шаблон `spatial-biology` содержит две полные редактируемые сцены на RU/EN (16 состояний): мечение → отмывка → капля → лизис → совместный захват, затем три разные роли клеточного штрихкода, признака и UMI. Создать: `python3 create.py ../my-3d-lesson --template spatial-biology --palette ocean`. [Автономный пример](examples/spatial-biology.html). Геометрия, число молекул и траектории условны; совместный захват отделён от последующего синтеза. Компоненты и рецепты входят в каждый новый проект, но другие шаблоны не запускают эти сцены.

Готовые кирпичики трасс, камеры, локатора, общей глубины и ползунка; переносимый импортёр PDB; пример 7BG9 с проверенным происхождением. Создать: `python3 create.py /новая/папка --template molecular-views --title "Комплекс и матрица" --palette ocean`. [Автономный пример](examples/molecular-views.html).

Связанные атомы, общий вид при увеличении, стэкинг, петля и рецептор, гидратированный Mg²⁺, пары и пространственная геометрия. Создать: `python3 create.py /новая/папка --template rna-folding --title "Как складывается РНК" --palette ocean`. [Автономный пример](examples/rna-folding.html).

Обычный вход запускает рассказ; глава проигрывается с начала, ползунок и крупный план останавливают движение. QA и reduced motion остаются неподвижными. В `F.driver.to` добавлен необязательный `ease`, включая `linear`; прежний default сохранён. Руководство: [chemistry-bridge.md](docs/chemistry-bridge.md). Проверяйте сами движения и промежуточные состояния, прежде чем переносить пример в новый урок.

Объяснения различают барьер и итог реакции, равновесную долю и отдельный сайт, засветку и диффузию, силу и поток ионов, поле и траекторию фотона, непрерывную кинетику и округлённый ансамбль. Исходники и переносимое руководство доступны через `python3 docs/navigation/route.py --show chemistry-bridge`.

**Новое в 0.16.0:** [«Химия → биология»](docs/chemistry-bridge.md) — отдельный редактируемый урок с химическими схемами и численными моделями: `create.py /новая/папка --template chemistry-bridge --palette ocean`. [CH](docs/chemistry.md) предоставляет атомы, связи и реакции; [PH](docs/physical-chemistry.md) — расчёты с явными единицами и допущениями. Оба модуля, рецепты и руководства входят в каждый новый проект. Автономный пример: `python3 tools/build-chemistry-bridge.py`, проверка воспроизводимости: `--check`; браузерная QA включается через `?qa=1`.

**Новое в 0.15.0:** [повторяемая проверка семи молекулярных элементов](docs/molecular-check.md) оформлена как отдельный редактируемый шаблон: `create.py /новая/папка --template molecular-check --palette ocean`. Он показывает авторские состояния новых акторов, движение и крупный план, сохраняя обычную оболочку RU/EN. Это визуальная проверка схем, а не вычисление биофизики. Необязательный режим браузерной QA включается через `?qa=1`; автономный пример собирается командой `python3 tools/build-molecular-check.py` и проверяется с `--check`.

[Крупный план](docs/molecular-inspection.md) позволяет рассмотреть тот же объект или выбранную часть в доступном с клавиатуры окне; это зафиксированный кадр схемы. [Регуляция](docs/molecular-regulation.md), [обработка РНК](docs/molecular-rna-processing.md) и общий механизм регистрации сцен входят в новые проекты. Иерархия тонких обычных контуров и выразительного акцента сохранена.

**Новое в 0.13.0:** [молекулярный атлас](examples/molecular-atlas.html) и [API молекулярных акторов](docs/molecular.md): ДНК, Cas9, гайдовые РНК, полимераза, нуклеосома, белки репрессии и элементы экспрессии гена. Это схематичные рисунки, управляемые авторскими состояниями; молекулярная физика не вычисляется. Создать редактируемый вариант: `create.py /новая/папка --template molecular --palette ocean`.

Галерея содержит тринадцать небольших примеров с учебными данными, полностью подготовленных на RU/EN: 52 пояснения и 26 вопросов с ответами. Переключение языка сохраняет сцену, шаг, ввод и анимацию. На холсте остаются заголовок, рисунок и текущая объясняющая реплика; определения, вопросы и сведения об источнике находятся в едином пространстве чтения.

Для новой темы начните со [сценария видимых операций](docs/storyboard.md) и [законченного рецепта преобразований](examples/representation-journey.html). Библиотека включает текстовые блоки с измеряемыми внутренними отступами, движение постоянных объектов между расположениями и явный перенос общего объекта в следующую сцену. [Исходник рецепта](starter/js/recipes/representation-journey.js) входит в каждый создаваемый проект.

[Независимый пример: клетки и доноры](examples/independent-evidence.html) показывает собственную композицию автора, который использовал только библиотеку: четыре сцены, две численные API и новая интерактивная модель.

**Новое в 0.10.0:** [лаборатория научных методов](examples/scientific-methods.html) — девять работающих объяснений статистики, scRNA-seq, генетики и геометрии. [Репертуар и правила самостоятельной композиции](docs/scientific-repertoire.md) помогают выбрать действие по вопросу; автор может создавать собственные сцены и компоненты.

**Новое в 0.11.0:** [связное объяснение](examples/explanation-bridges.html) — четыре сцены с повторяющейся картой, чтением квантилей, сгущением сетки и пошаговым расчётом расстояния и центральной кривой. ## Новый урок одной командой

**Исправлено в 0.12.1:** в повторяющейся карте каждый шаг имеет свой смысловой акцент и подпись действия. Пройденные связи сохраняются; отдельная кнопка повторяет только известный маршрут. В шаблон, руководства и проверки перенесены правила различения текущего, пройденного и будущего. [Как устроено пошаговое объяснение](docs/pipeline-synthesis.md).

**Дополнение к руководствам:** [зазоры между подписями и линиями](docs/label-clearance.md) — резервирование места вокруг формул, подписи с нужной стороны оси, безопасные области при движении и проверка окружностей, эллипсов и толстого анимированного штриха. Руководство и инструкции автора входят в каждый новый урок. Это приёмы композиции на существующих API; автоматического размещения подписей они не добавляют.

**Новое в 0.12.0:** [общая картина с двумя входами](examples/pipeline-synthesis.html) — четыре сцены, которые постепенно связывают модель, построение клеток и независимую проверку среднего и разброса. Одна учебная модель, постоянные IDs и интерактивный финал. Создать редактируемый вариант: `create.py /новая/папка --template synthesis`.

[SVG-кнопки](docs/interaction-regions.md) реагируют по всей площади, поддерживают Tab/Enter/Space, перевод доступного названия и отдельный индикатор фокуса. [Инспектор зон нажатия](docs/hit-region-audit.md) проверяет перекрытия и попадание в пустые участки без активации контролов. В [рекомендациях по композиции](docs/explanation-design.md) сохранён опыт разделения значков, чисел, количественных отметок и условных схем. Существующие уроки обновляются явно по [инструкции](docs/upgrading.md).

Плавная интерполяция стала численно устойчивее возле конечной точки: округление больше не выводит допустимый прогресс чуть выше 1 и не прерывает расчёт с ограниченными параметрами.

```sh
python3 create.py ../new-lesson --title "Название нового урока"
```

В новой папке работает галерея примеров. Откройте `index.html` или запустите `python3 serve.py --port 8150` из этой папки. Для одного переносимого файла выполните `python3 build/bundle.py`; результат — `dist/lesson.html`.

Можно передать `--source-url`, `--source-label`, `--lang en`, а также `--background white`, `--palette ocean` и `--font serif`. Параметр `--lang` задаёт начальный язык; оба авторских пакета входят в урок и автономную сборку. Название и источник находятся в `js/config.js`; содержание — в `js/episodes/`, переводы — в `js/i18n/`. Команда отказывается перезаписывать непустую папку. Новый урок содержит собственную копию движка, руководств и лицензий шрифтов, поэтому работает без исходной папки библиотеки.

## Готовые части

Для запуска научной лаборатории в новом проекте используйте `create.py /absolute/path/to/project --template methods`. Её три модуля и рецепты также входят в обычный проект; подробные API: [статистика](docs/statistics.md), [биология](docs/biology.md), [геометрия](docs/geometry.md). Сборка автономного примера библиотеки: `python3 tools/build-methods.py`, проверка воспроизводимости: та же команда с `--check`.

| Часть | Возможности |
|---|---|
| Проигрыватель | Шаги, возврат, адрес `#эпизод.шаг`, оглавление, пояснения, вопросы, поиск, RU/EN, скорость, полный экран и reduced motion |
| Телефон | Свайп по рисунку; штатный pinch браузера и перемещение увеличенной страницы; прокрутка текстовых панелей |
| `F` | Сцена, подписи, линии, стрелки, клетки, группы, состояние, интерполяция, фазы и локальное управление анимацией |
| `L` | Внутренние отступы, строки/столбцы, перенос полного переведённого текста, измерение предназначенных блоков и пересчёт при смене шрифта |
| `T` | Пояснения, ползунки, кнопки, вопрос → подсказка → ответ, окно источника |
| `K` | Общие шкалы, безопасная область, точное приближение рисунка, гистограмма, повторы, последовательности, матрицы, разбиение наблюдений, сравнение предсказаний, повторные выборки, precision/recall и пространственные точки |
| `B` / `K.molecular` | Постоянные молекулярные SVG-акторы, локальные точки крепления, уровни акцента и крупный план |
| `V3` | Процедурные объёмные молекулы, поверхность клетки, бусина и праймеры, капля, захват и три кода; отдельная ветка `three-dimensional` |
| `CH` / `PH` | Химические SVG-схемы и независимые численные модели с указанными условиями применимости |
| Экспорт | HTML со встроенными шрифтами, кодом и локальными изображениями |

`F.motionTrack` связывает одни и те же объекты с несколькими расположениями; `F.shared` задаёт осмысленную связь между соседними сценами. Для проверки запустите сервер созданного урока и откройте `build/inspect.html`: инструмент измеряет внутренние блоки всех состояний и записывает промежуточные кадры. Он отделён от итоговой презентации и не добавляет контролов зрителю.

[Каталог тринадцати примеров](docs/reference-patterns.md) связывает каждую учебную задачу с готовым эпизодом и API. Для нового урока достаточно этой библиотеки и предоставленного первичного материала: другие презентации не нужны. Примеры выбирают по смыслу; они не задают обязательный план будущей истории. Учебные числа не становятся результатами новой статьи. Автор готовит содержание, оба перевода, изображения и проверяет источники.

В текущей версии в «Ещё → Оформление» доступны чёрный/белый фон, три палитры и два шрифта: Source Sans 3 и Source Serif 4. Выбор сохраняется и не сбрасывает текущую сцену. Компактная оболочка сохраняет пять постоянных контролов, меню дополнительных действий и одну панель чтения. Её геометрия не зависит от языка, числа шагов или подписей кнопок. Существующий урок обновляется по [upgrading.md](docs/upgrading.md); замена библиотеки сама по себе его не меняет.

## Работа с Codex

Склонируйте всю библиотеку и подключите включённый навык к Codex:

```sh
git clone https://github.com/eizorerad/visual-lesson-kit.git
cd visual-lesson-kit
python3 tools/install-codex-skill.py
python3 tools/install-codex-skill.py --check
```

Затем откройте задачу Codex в папке для нового урока. Пример запроса:

> Используй $visual-lessons. Сделай обучающий визуальный урок по приложенной статье, используя только PDF и Visual Lesson Kit. Подготовь русскую и английскую версии.

Установщик создаёт ссылку на навык в `~/.agents/skills/visual-lessons` и оставляет существующую установку без изменений. Если навык не появился, перезапустите Codex. Сохраните всю папку библиотеки: навык использует её компоненты и руководства. [Полная инструкция](docs/codex-setup.md) описывает обновление, перенос и проверку. Генератор требует Python 3.10+; Codex, npm и сторонние Python-пакеты для него не нужны.

- [Галерея](starter/index.html) — запускаемые образцы.
- Автономная галерея — создайте `gallery` и выполните `python3 build/bundle.py` в папке урока.
- [Отдельный пример](examples/mean-spread.html) — урок про среднее и разброс; [его исходники и пересборка](examples/README.md).
- [Создание содержания](docs/authoring.md), [каталог примеров](docs/reference-patterns.md) и [API](docs/components.md).
- [Оформление](docs/theme.md), [компактная оболочка](docs/shell.md) и [обновление урока](docs/upgrading.md).
- [Вопросы и конспект](docs/questions.md), [RU/EN](docs/languages.md), [мобильные жесты](docs/mobile-gestures.md).
- [Проверка качества](docs/qa.md) и [происхождение кода и шрифтов](docs/provenance.md).

## Проверки библиотеки

```sh
python3 -m unittest discover -s tests -v
npm install
npm test
```

Node/jsdom нужны только для разработки. При готовой установке jsdom можно использовать `NODE_PATH`; пути к чужим проектам в тесты не зашиты. Расчётная проверка не заменяет просмотр в браузере; синтетические pointer events не подтверждают pinch на физическом экране.
